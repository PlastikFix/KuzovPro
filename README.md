# KUZOV PRO — прототип приложения для кузовного ремонта

## Что уже работает
- Адаптивный интерфейс для телефона и компьютера.
- Создание сметы и карточки заказа.
- Загрузка фотографий и просмотр миниатюр в текущей сессии.
- Ручной калькулятор работ, материалов, расходов, скидки и рыночной корректировки.
- Черновик сметы по выбранному типу повреждения и сложности (это правила, не компьютерное зрение).
- Редактируемый прайс.
- Поиск заказов, статусы, повторное открытие сметы, удаление.
- Экспорт заказов в CSV.
- Печать сметы / сохранение через системный диалог печати в PDF.
- Локальное сохранение данных в браузере через localStorage.

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в современном браузере.
3. Для теста создайте оценку, добавьте фото, сформируйте смету и сохраните заказ.

Можно также раздать папку через любой статический веб-сервер. В текущем виде данные остаются в конкретном браузере/устройстве и не синхронизируются между устройствами.

## Архитектура следующей версии для реальной эксплуатации
- Frontend: React/Next.js + TypeScript, адаптивный UI.
- Backend API: FastAPI или Node.js/NestJS.
- БД: PostgreSQL (клиенты, авто, заказы, строки сметы, прайс, история изменений).
- Хранилище фото: S3-совместимое хранилище с приватными ссылками и сроком хранения.
- Авторизация: индивидуальная учётная запись владельца, сессии, роли при необходимости.
- AI-сервис: серверный endpoint, который принимает фотографии и возвращает структурированную гипотезу повреждений, уверенность, недостающие ракурсы и возможные виды работ. API-ключ хранится только на сервере.
- Ценообразование: расчёт из локального прайса + настраиваемые коэффициенты по региону/сложности/типу автомобиля; рыночные данные должны поступать из проверяемого источника, а не выдаваться за автоматически известную среднюю цену.
- Документы: генерация PDF на сервере, версии смет и согласование.
- Надёжность: резервные копии, журнал действий, согласие на обработку персональных данных, политика хранения фотографий.

## Важно
ИИ-анализ изображений и подключение к проверенным актуальным рыночным тарифам в этом прототипе не реализованы. Кнопка формирования сметы использует простые правила и выбранные пользователем признаки повреждения. Не используйте результат как окончательную оценку без осмотра мастером.
