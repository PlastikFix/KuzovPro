# KUZOV PRO — Supabase Edition

## Важно
- В HTML нет встроенных паролей. Пользователи входят через Supabase Auth; пароли хранятся и проверяются Supabase.
- Не вставляйте secret/service_role key в сайт. Используется только publishable key.
- ИИ вызывается через Supabase Edge Function, поэтому OpenAI API key не попадает в браузер.
- Перед использованием в реальной мастерской проверьте доступы и сделайте резервную копию.

## 1. Подключить проект
1. Откройте `index.html` в редакторе кода (например, VS Code).
2. Найдите в начале скрипта `SUPABASE_URL` и `SUPABASE_PUBLISHABLE_KEY`.
3. Вставьте свой Project URL и publishable key вместо текстов `PASTE_...`. Кавычки оставьте.
4. Загрузите `index.html` в свой GitHub Pages репозиторий вместо старого файла и сделайте Commit.

## 2. Таблица и политики
В Supabase → SQL Editor → New query вставьте `setup.sql` целиком и нажмите Run. Если вы уже запускали похожий SQL, скрипт безопасно добавит нужные колонки и пересоздаст названные политики.

Политика в этом стартовом комплекте разрешает любому вошедшему пользователю читать и редактировать все заказы — это соответствует сценарию, где владелец видит все работы, но перед публичным запуском нужно сузить доступы, если работники не должны видеть все заказы.

## 3. Создать аккаунты
Supabase → Authentication → Users → Add user → Create new user.
Создайте отдельный аккаунт для владельца и для каждого работника. Введите email и назначьте свой пароль в панели Supabase. Пароли не прописываются в HTML и не отображаются на экране входа.

Для отображения владельческих разделов у владельца задайте в `app_metadata` поле `role` со значением `owner` через доверенную серверную административную операцию. Для работников роль можно оставить `worker`. Не выдавайте `service_role` ключ браузеру. Если не настроить `app_metadata`, пользователи войдут как работники.

## 4. Подключить ИИ (нужен платный API-ключ модели)
1. Установите Supabase CLI и войдите: `supabase login`.
2. Из корня этой папки привяжите проект: `supabase link --project-ref YOUR_PROJECT_REF` (project ref — часть URL проекта до `.supabase.co`).
3. Добавьте секрет: `supabase secrets set OPENAI_API_KEY=YOUR_OPENAI_API_KEY`.
4. Разверните функцию: `supabase functions deploy ai-assess`.
5. В Supabase → Edge Functions проверьте, что `ai-assess` появилась.

OpenAI API key создаётся в панели OpenAI Platform. Это отдельная оплата API; подписка ChatGPT не включает API-расходы. Не вставляйте ключ в `index.html`, GitHub или чат.

## 5. Проверка
- Откройте опубликованный GitHub Pages сайт.
- Войдите email/паролем Supabase.
- Создайте тестовый заказ, затем откройте сайт на другом устройстве и войдите тем же или другим разрешённым аккаунтом.
- Для ИИ загрузите фото и нажмите «ИИ-помощник». Если функция не развёрнута или секрет не добавлен, приложение покажет ошибку.

Приложение — стартовая интеграция; оно не было проверено на вашем Supabase-проекте, пока вы не выполните эти шаги.
